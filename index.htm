📐 Recisor Layout Showcase

Recisor is a lightweight, zero-dependency layout orchestrator for managing resizable panels, multi-pane sibling grids, and docked edge sidebars using standard CSS flexbox models.

Zero Dependencies Sibling Grids Parent/Child Sidebars Event Driven

1. Sibling Panels

Recisor.createSiblingWorkspace(container)

Drag bars are automatically injected between every consecutive sibling element. Supports automatic percentage normalization and minimum boundary constraints via data-recisor-min.

2. Left Sidebar (Parent/Child)

Recisor.createParentChildWorkspace(sidebar, { side: 'right' })

Injects an internal handle along the right edge of a panel. The neighboring content panel uses flex-grow: 1 to naturally fill the remaining space without layout jumps.
